# Python Practice

This repository is a dedicated space for practicing Python programming, solving coding challenges, and learning new concepts.

## 🚀 Goals
- Master core Python concepts (loops, functions, OOP).
- Practice problem-solving and algorithmic thinking.
- Keep track of coding progress.

## 📁 Repository Structure
- `/basics`: Simple scripts covering fundamental syntax.
- `/challenges`: Solutions to various coding problems.

## 🛠️ How to Run
To run any of the scripts locally, make sure you have Python installed, clone this repo, and run:
`python filename.py`
